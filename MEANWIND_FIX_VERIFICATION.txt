ISSUES FIXED
============

1. Formatter Forced Integer (CRITICAL)
--------------------------------------
Problem: ClimateCard::fmt() called Wx::conv(..., -1) for Wind unit
  - -1 parameter explicitly forces whole numbers
  - Real 4.6 mph displayed as "5"
  - Real 0.8 mph displayed as "1"
  - Real 1.26 mph displayed as "1"

Fix: Changed parameter from -1 to 1
  File: site/ClimateCard.php line 272
  Before: return Wx::conv($v, $unit, $showUnit, false, -1); // whole numbers
  After:  return Wx::conv($v, $unit, $showUnit, false, 1);  // 1 decimal place for mean wind

Effect: All mean wind values now display to 1 decimal place
  - Normal 4.6 mph → "4.6 mph" (not "5 mph")
  - Today 0.0 mph → "0.0 mph" (not "0 mph")
  - Record 0.8 mph → "0.8 mph" (not "1 mph")
  - Record 15.6 mph → "15.6 mph" (not "16 mph")

2. Cache Not Invalidated (CRITICAL)
------------------------------------
Problem: CACHE_VERSION stayed at 4 after dp change
  - Old cache has records computed/stored with integer rounding
  - Served cached records differ from fresh calculations
  - Wrong tie dates due to rounded comparisons

Example Discrepancies (from actual verification):
  Day low:   Expected 0.8@2020-11-07 (n=1), Served 1@2020-11-07
  Day high:  Expected 8.0@2018-11-07 (n=1), Served 8 with 5 ties (wrong)
  Month low: Expected 0.0@2021-11-15 (n=1), Served 0 with 7 ties (wrong)
  All low:   Expected 0.0@2021-11-15 (n=1), Served 0 with 35 ties (wrong)
  All high:  Expected 16.4@2020-02-09 (n=1), Served 16 with 2 ties (wrong)

Fix: Bumped CACHE_VERSION from 4 to 5
  File: site/ClimateCard.php line 16
  Before: const CACHE_VERSION = 4;
  After:  const CACHE_VERSION = 5;

Effect: Cold cache rebuild required
  - Existing v4 cache rejected (version mismatch)
  - Fresh rebuild uses native precision throughout:
    * Accumulate records at native values
    * Compare for min/max at native precision
    * Identify true ties (not rounded artifacts)
    * Convert to user units only for display
  - Dates/years now accurate for actual ties

3. CSS Cache Buster Unchanged (DEPLOYMENT RISK)
------------------------------------------------
Problem: mainstyle_v5.css changed but URL unchanged
  - Page.php still referenced ?20261102v
  - Deployed browsers would serve stale CSS
  - YTD full-width layout might not render

Fix: Updated cache buster to next free version
  File: site/Page.php line 148
  Before: href="/$styleSheet.css?20261102v"
  After:  href="/$styleSheet.css?20261102w"

Effect: Browsers fetch updated stylesheet
  - YTD full-width layout CSS loads
  - No stale cache in production
