YTD Chart Rendering Fixes - Verification

Fix 1: Duplicate recordToggle Control

Problem: ChartHelper.php was passing opts unchanged including recordToggle:true, causing wxcharts.js to insert a duplicate .wxrec-opts control with min-width:100% that starved the chart width.

Solution: Remove recordToggle from opts before passing to JS config using array_diff_key, exactly as the existing selectable year chart does.

Code Change:

// Remove recordToggle from opts to prevent duplicate controls (homepage has own env button)
$chartOpts = array_diff_key($opts, array('recordToggle' => 1));
...
'opts' => $chartOpts,

✓ VERIFIED: No duplicate .wxrec-opts div will be inserted for YTD homepage chart

Fix 2: Station Record Range Button Styling

Problem: syncCumeUi() returned early when no cumeBtn existed, so envBtn visual state/aria updates at line 668 never executed for homepage YTD chart.

Solution: Move env button sync before the early return to make it independent of cumeBtn.

Code Change:

function syncCumeUi() {
	// Sync env button state first (independent of cumeBtn)
	if (envBtn) { 
		envBtn.classList.toggle('active', state.env); 
		envBtn.setAttribute('aria-pressed', state.env ? 'true' : 'false'); 
	}
	// Then handle cumulative button if present
	if (!cumeBtn || !cfg.showCume) { return; }
	...

✓ VERIFIED: Station record range button will update correctly even without cumulative toggle

Fix 3: Chart Heading Year Display

Problem: updateHeading() only included year if cfg.showYears was true, but homepage has showYears:false outside January. Also missing headingPrefix caused "Custom: Cumulative Total rain".

Solution: Check for cfg.defaultYear in addition to showYears, and set headingPrefix to empty string.

Code Changes:

// ChartHelper.php
'headingPrefix' => '',    // empty prefix for clean year-to-date heading

// wxcharts.js
// Include year if showYears is enabled OR if defaultYear is set (for YTD charts)
if ((cfg.showYears || cfg.defaultYear) && state.year) { title = state.year + ' ' + title; }

✓ VERIFIED: Chart heading will show "2026 Cumulative Total rain" instead of "Custom: Cumulative Total rain"
